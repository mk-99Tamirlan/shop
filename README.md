# Мини-магазин
Один проект, этапы 0–2. Следующие лабораторные продолжают ветку main.

## Запуск и измерения
Нужны Docker Engine, Compose, Git и Python 3.12+. Порт 8080 должен быть свободен. Если 5432 занят, измените только внешний порт PostgreSQL и локальный DATABASE_URL.

В PowerShell из папки shop: `powershell -ExecutionPolicy Bypass -File .\run-labs.ps1`.
Скрипт использует один и тот же том pgdata и не удаляет данные. Результаты сохраняются в results. Порог k6 может быть превышен: это результат измерения, не повод подменять цифры.

Теги lab-0, lab-1, lab-2 обозначают подготовленные версии исходников, а не доказательство запуска. Для сдачи нужны реальные измерения и снимки экрана. После проверки добавьте отдельный коммит с результатами.

Swagger: http://localhost:8080/docs
